# Phone Htet Paing — Portfolio

This is a front-end portfolio website built with:
- HTML
- CSS
- JavaScript

## Folder structure

phonehtetpaing-portfolio/
├── index.html
├── style.css
├── script.js
└── images/

## Add your profile photo

Create an `images` folder and add your photo, for example:

images/profile.jpg

Then in `index.html`, replace the profile placeholder with:

<img src="images/profile.jpg" alt="Phone Htet Paing">

## Add project photos

Put your project screenshots inside `images/`.

Example:
images/flight-booking.jpg
images/lan-design.jpg

Then replace the project placeholder `<div>` with an `<img>` element.

## Run locally

Double-click `index.html`, or open it in VS Code and use Live Server.

## Upload to hosting later

When your Z.com hosting is ready, upload:
- index.html
- style.css
- script.js
- images/

to your hosting's public website directory (normally `public_html`).

Before making the website public, review the contact information and decide whether you want your phone number and university email publicly visible.
